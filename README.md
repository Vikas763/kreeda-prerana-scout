# Kreeda Prerana Scout

Kreeda Prerana Scout is a sports scouting and athlete performance tracking platform designed to help coaches and scouts efficiently manage athlete information and performance metrics.

The platform allows scouts to register athletes, monitor performance statistics, and maintain a centralized athlete database through a modern and responsive dashboard interface.

---

## Features

- Athlete registration system
- Performance tracking dashboard
- Sprint time and jump height analysis
- Athlete card management
- Delete athlete functionality
- Responsive UI design
- Cloud database integration using Supabase
- Real-time data persistence
- Dark-themed modern dashboard

---

## Technologies Used

- React
- TypeScript
- Vite
- Tailwind CSS
- Supabase
- TanStack Query

---

## Problem Statement

Managing athlete performance data manually can be inefficient and difficult for sports organizations and scouts.

Kreeda Prerana Scout provides a centralized digital platform to simplify athlete registration, performance tracking, and scouting analysis.

Install dependencies

npm run dev
